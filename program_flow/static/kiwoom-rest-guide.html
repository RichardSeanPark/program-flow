데이터가 아직 없으면 대기 화면이 표시됩니다. 일시적인 연결 실패는 자동으로 재시도하며, 기존 데이터는 보존합니다.

로그: %LOCALAPPDATA%\ProgramFlow\logs\program-flow.log

종료와 데이터 보관

브라우저를 닫아도 알림 영역의 Program Flow가 실행되는 동안 수집합니다. 알림 영역 메뉴에서 종료할 수 있습니다. API 키는 이 PC에 암호화해 저장합니다. 브라우저 쿠키를 삭제하면 기존 데이터에 접근할 수 없으니 주의하세요.

주문 기능 없이 데이터만 조회하는 도구입니다.
